# English Learning Bot — Telegram-бот для изучения английского

Бот для ежедневной практики английского: до 15 новых слов и фраз в день
(общая лексика, повседневные и деловые диалоги + технический английский по
инженерии/производству), каждое слово отдельным сообщением — с картинкой-
иллюстрацией и голосовым произношением, интервальное повторение, голосовая
практика и small talk с распознаванием речи и проверкой грамматики,
напоминания дважды в день, streak и мотивация. Словарная база — 430+ слов
и словосочетаний.

Голосовой модуль работает **полностью бесплатно** (без платных API-ключей):
распознавание речи через бесплатный Google Web Speech API, озвучка через
gTTS, проверка грамматики через публичный сервер LanguageTool. Из-за этого
диалог построен по заранее подготовленным сценариям (темы + follow-up
вопросы), а не как полностью свободный ИИ-чат — но всё распознавание
твоей речи, грамматические подсказки и произношение — настоящие и живые.
Если позже захочешь более "живой" ИИ-диалог — в конце README есть раздел
о том, как за пару минут подключить платный OpenAI-ключ.

## Что нужно для запуска

- Telegram-аккаунт (создать бота может любой)
- Python 3.11+ (подойдёт и 3.10)
- Установленный `ffmpeg` (нужен для конвертации голосовых сообщений)
- Место, где бот будет работать постоянно: свой компьютер (пока он включён
  и online), либо бесплатный/недорогой облачный хостинг (ниже — инструкция
  для Railway)

## Шаг 1. Создать бота через @BotFather

1. Открой Telegram, найди **@BotFather** (это официальный бот Telegram).
2. Напиши ему `/newbot`.
3. Придумай имя бота (например, "My English Coach") и username, который
   обязательно должен заканчиваться на `bot` (например, `zhalgas_eng_bot`).
4. BotFather пришлёт тебе **токен** — длинную строку вида
   `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`. Это и есть `BOT_TOKEN`.
   Никому его не показывай — это как пароль от бота.

## Шаг 2. Настроить проект

1. Распакуй архив с этим кодом в отдельную папку.
2. Скопируй `.env.example` в `.env`:
   ```
   cp .env.example .env
   ```
3. Открой `.env` и вставь свой токен в строку `BOT_TOKEN=...`.
4. При желании поменяй время напоминаний (`MORNING_HOUR`, `EVENING_HOUR`) —
   по умолчанию 08:00 и 19:30 по времени Asia/Qyzylorda (Кызылорда, UTC+5).

## Шаг 3а. Запуск локально (на своём компьютере)

```bash
# 1. Установи ffmpeg (один раз)
#    Windows: скачай с https://ffmpeg.org/download.html и добавь в PATH
#    Mac:     brew install ffmpeg
#    Linux:   sudo apt install ffmpeg

# 2. Создай виртуальное окружение и поставь зависимости
python -m venv venv
source venv/bin/activate      # на Windows: venv\Scripts\activate
pip install -r requirements.txt

# 3. Запусти бота
python bot.py
```

Бот будет работать, пока запущен этот процесс (пока открыт терминал и
включён компьютер). Найди своего бота в Telegram по username и напиши
`/start`.

## Шаг 3б. Бесплатный деплой на Railway (чтобы бот работал 24/7)

Railway — удобный сервис, у которого есть бесплатный пробный баланс,
достаточный для такого лёгкого бота.

1. Зайди на https://railway.app и зарегистрируйся (можно через GitHub).
2. Залей код этого проекта к себе на GitHub (создай новый репозиторий и
   загрузи туда файлы), либо в Railway есть кнопка "Deploy from local
   folder" через Railway CLI.
3. В Railway нажми **New Project → Deploy from GitHub repo**, выбери свой
   репозиторий.
4. Убедись, что Railway определил проект как Python-приложение. Если
   нужно — добавь файл `Procfile` (уже включён в этот проект) со строкой:
   ```
   worker: python bot.py
   ```
5. В разделе **Variables** добавь переменные окружения из `.env`
   (как минимум `BOT_TOKEN`).
6. В разделе **Settings** убедись, что для ffmpeg используется
   `nixpacks` (Railway обычно ставит ffmpeg автоматически по `nixpacks.toml`,
   который уже включён в проект).
7. Разверни проект — Railway покажет логи, там должно появиться
   "Бот запущен. Ожидание сообщений...".

Если Railway не подходит — тот же принцип работает на Render (Background
Worker, не Web Service), Fly.io, VPS (DigitalOcean/Timeweb) или даже на
Raspberry Pi дома.

## Как пользоваться ботом

- `/start` — регистрация и первая подборка слов
- `/today` — показать слова, которые пришли сегодня
- `/quiz` — квиз на повторение слов (пиши перевод в ответ)
- `/talk` — начать разговорную практику: бот даёт тему, ты отвечаешь
  **голосовым сообщением**, бот распознаёт речь, мягко указывает на ошибки
  грамматики и продолжает диалог follow-up вопросом (голосом и текстом)
- `/pronounce слово` — услышать произношение любого слова или фразы
- `/tips` — советы, как начать думать на английском уже сейчас
- `/stats` — streak, количество выученных слов
- Просто отправь голосовое сообщение в любой момент — бот расшифрует его
  и подскажёт, что улучшить

Утром бот сам присылает новую порцию из до 15 слов, вечером — напоминание
повторить слова через `/quiz` и тему для разговорной практики. Каждое
слово приходит отдельным сообщением: картинка-иллюстрация с подписью
(слово, перевод, определение, пример), затем короткое голосовое с
произношением именно этого слова — специально не одной общей звуковой
дорожкой на все слова, чтобы было легче запоминать каждое по отдельности.
Из-за картинок и голоса рассылка занимает пару минут — слова будут
приходить одно за другим, это нормально.

## Про твой уровень и содержание

По приложенному сертификату Duolingo у тебя уровень **B1 (Intermediate)**,
общий балл 70, устная речь и понимание на слух — сильные стороны (75),
письмо — то, что стоит подтянуть (65). Сейчас около 65% ежедневных слов —
общая лексика, повседневные диалоги (магазин, кафе, телефон, врач,
путешествия) и деловое общение (переписка, встречи, small talk на работе),
35% — технический английский по инженерии и производству (сборочная линия,
контроль качества, обслуживание оборудования, проектная работа, безопасность,
логистика). Соотношение и максимум слов в день можно поменять через
`TECHNICAL_SHARE` и `NEW_WORDS_PER_DAY` в Variables/`.env`.

В базе сейчас 430+ слов и словосочетаний (250 общих + 180 технических) —
хватит примерно на месяц новых слов даже без повторов, а дальше в дело
вступает интервальное повторение уже выученного.

Хочешь другую техническую область или другой набор тем для small talk —
просто отредактируй файлы `data/words_technical.json` и
`data/conversation_prompts.json` (формат там простой JSON, можно менять
и добавлять свои слова/темы).

## Опционально: подключить "умный" ИИ-диалог (платно)

Бесплатный режим ведёт разговор по сценариям — это уже даёт настоящую
голосовую практику, но не заменяет полностью живого собеседника. Если
захочешь, чтобы бот отвечал куда более гибко и свободно (как настоящий
GPT-собеседник):

1. Зарегистрируйся на https://platform.openai.com и создай API-ключ
   (потребуется привязать карту — оплата идёт по фактическому использованию,
   обычно это центы за диалог).
2. Установи дополнительную библиотеку: `pip install openai`
3. Впиши ключ в `.env`: `OPENAI_API_KEY=...`
4. В файле `utils/ai_brain.py` уже есть готовая функция
   `generate_smart_reply()` — в `handlers/smalltalk.py` в функции
   `process_talk_reply` замени вызов `ai_brain.pick_followup(prompt)` на
   `ai_brain.generate_smart_reply(transcribed_text, {})`, если
   `ai_brain.has_smart_mode()` возвращает `True`.

Это полностью опционально, бот прекрасно работает и без этого шага.

```
english_bot/
  bot.py                  — точка входа
  config.py                — настройки (читает переменные окружения)

  data/

    words_technical.json    — техническая лексика (инженерия/производство)
    conversation_prompts.json — темы для small talk и техразговоров
  handlers/                — обработчики команд и сообщений (включая tips.py)
  utils/
    spaced_repetition.py    — логика интервального повторения
    wordbank.py              — подбор ежедневных слов
    stt.py                   — распознавание речи (бесплатно)
    tts.py                   — озвучка (бесплатно)
    image.py                  — картинки-иллюстрации к словам (бесплатно)
    grammar.py                — проверка грамматики (бесплатно)
    ai_brain.py                — сценарии диалога + опциональный OpenAI-режим
    _compat.py                 — совместимость с Python 3.13+
```

## Картинки-иллюстрации к словам

Картинки генерируются бесплатно через публичный сервис Pollinations.ai —
без ключа и регистрации. Это сторонний бесплатный сервис "как есть": иногда
отвечает медленно или временно недоступен — в этом случае бот просто
пропускает картинку и присылает слово текстом и голосом, ничего не
ломается. Если картинки слишком часто не приходят или не нужны вовсе —
отключи их переменной `ENABLE_WORD_IMAGES=false` в Variables/`.env`.

## Частые проблемы

- **Бот не распознаёт голос / ошибка при обработке voice** — убедись, что
  установлен `ffmpeg` и он доступен в PATH (`ffmpeg -version` в терминале
  должен показать версию, а не ошибку).
- **Деплой падает с `ModuleNotFoundError: No module named 'audioop'`** —
  это значит, что хостинг поставил Python 3.13, где этот модуль убрали из
  языка (нужен библиотеке `pydub` для голосовых сообщений). В проекте уже
  есть файл `.python-version` (закрепляет Python 3.11) и строка
  `audioop-lts` в `requirements.txt` (бэкпорт модуля на случай 3.13) —
  если ошибка всё же вылезла, проверь, что оба этих файла точно попали
  в репозиторий на GitHub, и запусти деплой заново.
- **Грамматические подсказки не приходят** — публичный сервер LanguageTool
  иногда ограничивает частоту запросов; бот просто пропускает проверку в
  этом случае, ничего не ломается.
- **Бот перестаёт отвечать после закрытия терминала/выключения компьютера**
  — это нормально при локальном запуске, для круглосуточной работы нужен
  облачный хостинг (см. Шаг 3б).
